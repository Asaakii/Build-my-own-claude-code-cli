# 发布前安全回归清单

- [ ] `.env`、`.agent-code/` 与私有复盘未被 Git 跟踪。
- [ ] `agent-code status` 不回显密钥、模型标识或 Base URL。
- [ ] Plan Mode 下，写文件与 Shell 工具会被程序拒绝。
- [ ] 编辑和写 Shell 操作都要求一次性确认 ID；确认后不能复用。
- [ ] 删除、提权、网络、管道/重定向和工作区外路径被拒绝。
- [ ] 会话与项目记忆拒绝疑似凭据，损坏存储不会被静默覆盖。
- [ ] Skills 拒绝符号链接、越界路径与过大/无效文件。
- [ ] 子代理没有写工具；任务调度器不会并行分派写任务。
- [ ] Worktree 合并/删除有 `--confirm`，有改动的清理保留恢复路径。
- [ ] MCP 工具先确认、再校验 schema、再调用；输出受大小限制。
- [ ] Ruff、完整测试、Mock CLI 演示与发行物安装验证均通过。
