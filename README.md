# agent-code

一个从零实现、用于学习 Agent Harness 的 Claude Code 风格命令行工具。

## 当前进度

正在进行阶段 0：项目骨架、安全基线与测试环境准备。真实模型接入、文件工具与命令执行均尚未实现。

详细路线见 [学习计划.md](./学习计划.md)。

## 开发环境

- Python 3.12.13（见 `.python-version`）
- 依赖与命令将在下一步使用 `python -m pip` 管理；后续可按需要迁移到 `uv`。

## 安全约定

- 不提交 `.env`、会话记录或个人复盘。
- 真实凭据只从本机环境变量读取，不显示在终端输出或测试日志中。
- 在 Plan Mode 和权限系统完成前，不实现自动文件写入或命令执行。
